核心能力

构建于先进的 AI Agent 和稳健的工程设计之上，确保网络稳定性。

统一 AI Agent

由 LLM (OpenAI, DeepSeek, Gemini) 驱动。支持标准对话、RAG (知识增强) 和 ReAct (推理) 模式处理复杂任务。

RAG 知识库

基于 LanceDB 的向量存储。智能检索与重排序，为网络诊断和解决方案提供精准的上下文。

ReAct 推理引擎

Thought-Action-Observation 循环。自动选择工具查询设备、分析日志并自主执行修复。

并行执行

高效的多工具并发执行与依赖分析。安全地执行并行操作以加速诊断。

实时监控

统一的仪表盘用于流量分析、资源监控，具备多渠道通知能力 (Syslog, Webhooks, Telegram)。

故障自愈

自动修复流水线。检测接口宕机或高延迟等问题，并通过 Critic/Reflector 循环应用预定义的修复策略。

快速开始

使用 Docker 分分钟完成部署。

1. 下载镜像
# 拉取最新镜像 docker pull ghcr.io/btnalit/opsevo:latest
2. 运行容器
# 运行容器 docker run -d --name opsevo \ -p 8080:3099 \ -v opsevo-data:/app/backend/data \ -v opsevo-logs:/app/backend/logs \ ghcr.io/btnalit/opsevo:latest

查看 README 获取完整配置详情。
